# 🎙️ تبدیل گفتار به متن

> 🇬🇧 **[English](README.md)**

یک ابزار ساده و کاربردی **تبدیل گفتار به متن (Speech-to-Text)** که با استفاده از سرویس آنلاین تشخیص گفتار گوگل، فایل صوتی را به متن تبدیل می‌کند.

این اسکریپت برای پردازش فایل‌های صوتی طولانی طراحی شده و می‌تواند فایل را به بخش‌های کوچک‌تر تقسیم کند، در صورت بروز مشکل اتصال دوباره تلاش کند و متن نهایی را به‌صورت فایل UTF-8 ذخیره کند.

> [!NOTE]
> برای استفاده از این پروژه به اتصال فعال اینترنت نیاز دارید، زیرا تشخیص گفتار از طریق سرویس آنلاین Google انجام می‌شود.

---

## ✨ قابلیت‌ها

- 🎤 **تبدیل گفتار به متن** — تبدیل صدای ضبط‌شده به متن.
- 📁 **ورودی انعطاف‌پذیر** — امکان مشخص کردن مستقیم مسیر فایل صوتی یا پیدا کردن خودکار جدیدترین فایل `pars*.wav`.
- ⏱️ **پشتیبانی از فایل‌های صوتی طولانی** — فایل‌های طولانی به بخش‌های **۳۰ ثانیه‌ای** تقسیم می‌شوند.
- 🔄 **تلاش مجدد خودکار** — در صورت بروز خطای موقتی شبکه، درخواست تا **۳ بار** مجدداً ارسال می‌شود.
- 💾 **ذخیره خودکار متن** — متن خروجی به‌صورت فایل `.txt` با encoding `UTF-8` ذخیره می‌شود.
- 🌍 **پشتیبانی از زبان‌های مختلف** — امکان تغییر زبان تشخیص گفتار با استفاده از گزینه `-l`.
- 🚫 **عدم ذخیره خروجی** — با استفاده از `--no-save` می‌توانید ذخیره فایل متنی را غیرفعال کنید.
- ⚠️ **پیام‌های خطای دقیق** — برای خطاهای مختلف مانند نبودن فایل، فرمت نامعتبر، قطعی اینترنت و نبودن صدای قابل تشخیص، پیام مناسب نمایش داده می‌شود.
- 🧩 **رابط خط فرمان ساده** — اجرای پروژه از طریق Terminal / Command Line.

```bash
pip install SpeechRecognition

```

## 🚀 نحوه استفاده

### اجرای ساده

اگر فایل صوتی را مشخص نکنید:

```bash
python transcribe.py
```

اسکریپت به‌صورت خودکار جدیدترین فایل با الگوی زیر را پیدا می‌کند:

```text
pars*.wav
```

این قابلیت زمانی کاربردی است که فایل صوتی توسط یک اسکریپت ضبط صدا ساخته شده باشد و نام آن با `pars` شروع شود.

---

### 🎤 تبدیل یک فایل مشخص

می‌توانید مسیر فایل صوتی را مستقیماً وارد کنید:

```bash
python transcribe.py pars_test.wav
```

یا:

```bash
python transcribe.py my_voice.wav
```

---

## 🌍 تغییر زبان تشخیص گفتار

زبان پیش‌فرض پروژه فارسی است:

```text
fa-IR
```

برای تبدیل صدای انگلیسی به متن، می‌توانید از `en-US` استفاده کنید:

```bash
python transcribe.py my_voice.wav -l en-US
```

به همین شکل می‌توانید کد زبان موردنظر خود را مشخص کنید.

---

## 💾 مشخص کردن فایل خروجی

به‌صورت پیش‌فرض، متن تبدیل‌شده در کنار فایل صوتی و با فرمت `.txt` ذخیره می‌شود.

برای تعیین نام یا مسیر دلخواه:

```bash
python transcribe.py my_voice.wav -l en-US -o result.txt
```

مثلاً:

```text
my_voice.wav
result.txt
```

---

## 🚫 غیرفعال کردن ذخیره فایل

اگر فقط می‌خواهید متن را دریافت کنید و فایل `.txt` ایجاد نشود:

```bash
python transcribe.py my_voice.wav --no-save
```

---

## 🛠️ گزینه‌های خط فرمان

| گزینه | توضیحات |
|---|---|
| `FILE` | مسیر فایل صوتی ورودی |
| `-l`, `--language` | زبان تشخیص گفتار. پیش‌فرض: `fa-IR` |
| `-o`, `--output` | مسیر یا نام فایل خروجی |
| `--no-save` | غیرفعال کردن ذخیره متن در فایل |

### چند مثال

```bash
# پیدا کردن خودکار جدیدترین فایل pars*.wav
python transcribe.py

# تبدیل یک فایل مشخص
python transcribe.py pars_test.wav

# تبدیل صدای انگلیسی
python transcribe.py my_voice.wav -l en-US

# ذخیره با نام دلخواه
python transcribe.py my_voice.wav -l en-US -o result.txt

# تبدیل بدون ذخیره فایل متنی
python transcribe.py my_voice.wav --no-save
```

## ⏱️ پردازش فایل‌های صوتی طولانی

سرویس رایگان تشخیص گفتار گوگل برای فایل‌های صوتی طولانی می‌تواند محدودیت داشته باشد.

برای حل این مشکل، اسکریپت فایل صوتی را به بخش‌های **۳۰ ثانیه‌ای** تقسیم می‌کند:

```text
Audio File
    │
    ├── 0–30 seconds
    ├── 30–60 seconds
    ├── 60–90 seconds
    ├── ...
    │
    └── Combined Transcription
```

هر بخش به‌صورت جداگانه پردازش می‌شود و در پایان متن تمام بخش‌ها به یکدیگر متصل می‌شوند.

به این ترتیب امکان پردازش فایل‌های صوتی طولانی‌تر فراهم می‌شود.

## 🔄 تلاش مجدد خودکار

گاهی اوقات ممکن است به دلیل قطعی موقت اینترنت، یک درخواست تشخیص گفتار با خطا مواجه شود.

در این شرایط، اسکریپت به‌صورت خودکار تا **۳ بار** برای ارسال مجدد درخواست تلاش می‌کند.

> [!TIP]
> در صورت وجود مشکلات موقتی شبکه، نیازی به اجرای مجدد کل برنامه نیست؛ اسکریپت خودش درخواست ناموفق را دوباره امتحان می‌کند.

## 💾 فایل خروجی

به‌صورت پیش‌فرض، متن تشخیص داده‌شده در یک فایل `.txt` در کنار فایل صوتی ذخیره می‌شود.

برای مثال:

```text
my_voice.wav
my_voice.txt
```

فایل خروجی با encoding **UTF-8** ذخیره می‌شود تا متن فارسی و سایر زبان‌های Unicode به‌درستی نمایش داده شوند.

همچنین می‌توانید مسیر خروجی دلخواه تعیین کنید:

```bash
python transcribe.py my_voice.wav -o transcription.txt
```

## 🌍 پشتیبانی از زبان‌ها

زبان پیش‌فرض:

```text
fa-IR
```

برای مثال، برای تشخیص زبان انگلیسی:

```bash
python transcribe.py my_voice.wav -l en-US
```

کد زبان را می‌توان متناسب با زبان صحبت‌شده در فایل صوتی تغییر داد.
